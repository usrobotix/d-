# old/

Здесь хранятся исходные материалы, которые предшествовали разработке проекта **Диджитал плюс** (v2.0).

Статические HTML/CSS/JS файлы — прототипы, дизайн-макеты, брендбук и вёрстка страниц, созданные на этапе проектирования до написания кода.

| Файл | Описание |
|------|----------|
| Сайт.html | Прототип главной страницы |
| Услуги.html | Прототип страницы услуг |
| Кейсы.html | Прототип страницы кейсов |
| Отзывы.html | Прототип страницы отзывов |
| Контакты.html | Прототип страницы контактов |
| Брендбук.html | Брендбук компании |
| Логотип.html | Варианты логотипа |
| Логотип - финал.html | Финальный вариант логотипа |
| Финалисты.html | Финальные варианты дизайна |
| Узнаваемость.html | Концепция узнаваемости бренда |
| Документы.html | Прототип документов |
| FAQ.html | Прототип страницы FAQ |
| design-canvas.jsx | React-компонент дизайн-системы |
| site.css / pages.css / cases.css | Стили прототипов |
| site.js / cases.js / image-slot.js | Скрипты прототипов |
| marks.jsx / marks2.jsx | Компоненты меток |
| kase-*.html | Детальные страницы кейсов |
| _doc.png | Скриншот документации |

## Статус

Эти файлы не используются в production. Актуальный проект находится в ветке `claude/affectionate-lovelace-0116y` и будет смёржен в `main` после финального тестирования.
