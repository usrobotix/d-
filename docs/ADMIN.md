# ADMIN

URL: `https://prodigitalplus.ru/admin`

## Вход

- Email: `admin@prodigitalplus.ru`
- Пароль: задаётся при `pnpm db:seed` (по умолчанию `admin123`)
- **Сменить пароль после первого входа!**
- Токен JWT хранится в localStorage (`dp_token`), истекает через 7 дней

## Статусы заявок

`new` (Новая) → `in_progress` (В работе) → `done` (Готово) / `spam` (Спам)

## Уведомления о новых заявках

Каждая заявка с сайта дублируется:

- на email из настройки `NOTIFY_EMAIL` (по умолчанию `info@prodigitalplus.ru`);
- в Telegram-группу через бота.

Если уведомления перестали приходить — проверьте логи `pm2 logs dplus-api`
и переменные в `ecosystem.config.js` (SMTP_*, TG_BOT_TOKEN, TG_CHAT_ID).

## Загрузка файлов

Медиа → «Загрузить файл». Файлы → `apps/api/uploads/`, URL: `/uploads/filename.jpg`.
